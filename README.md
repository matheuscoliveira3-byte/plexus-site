# plexus-site

As páginas públicas do Plexus em https://plexusbrain.com: a inicial, a política de privacidade, os termos de uso e a página de obrigado da lista de espera. HTML estático, servido pelo GitHub Pages, sem cookie e sem pedido a outro serviço (as fontes de letra são do próprio site). O formulário da lista de espera ainda não envia nada: ele mostra para onde escrever.

A política está na versão 1.1, de 19/10/2026 (o ensaio da caixa da Microsoft no Mac mini), e os termos na versão 1, de 14/10/2026. A versão 2 da política entra antes da primeira pessoa convidada.
